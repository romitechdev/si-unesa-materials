# SI UNESA

Sistem Informasi — Universitas Negeri Surabaya.

Lecture notes and course materials for Sistem Informasi (Information Systems) at Universitas Negeri Surabaya (UNESA).

## Features

- Course / session sidebar with collapsible navigation
- Instant search with keyboard navigation
- Markdown reader with syntax highlighting
- Resource embeds (Drive, PDF, Video, Repo)
- Dark / Light mode
- Admin dashboard for content management
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Tech Stack

- Next.js (App Router)
- Tailwind CSS v4
- remark + rehype (syntax highlighting)
- gray-matter
- lucide-react
- next-themes
